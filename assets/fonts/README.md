# Fonts

Libertinus 7.051 (https://github.com/alerque/libertinus), SIL Open Font License 1.1 — see `OFL.txt`, copied unchanged from the release. The release's AUTHORS.txt and FONTLOG.txt are not copied (they list contributors' email addresses); see the upstream repository.

Committed: Serif Regular, Italic and Semibold, and Mono Regular, as released (OTF). `make` subsets them to WOFF2 (`tools/fonts.py`); the subsets and `fonts.rktd` are generated and not committed. The reserved font names are "Linux Libertine", "Biolinum" and "STIX Fonts", so the subsets may keep the Libertinus name.
